Implementation Notes

  • Circles represent sprite stand-ins. Each circle's foot touches the mid-rear (top vertex) of its tile — this is the spriteAnchor() calculation.
  • The dashed vertical center line divides hero columns (0–3) from enemy columns (4–7).
  • Row depth scale: front row (5) = 1.0 → back row (0) = 0.85^5 ≈ 0.444. Tile widths reflect this.
  • Hover any tile to see the gold highlight state (targeting-active mode CSS).
  • Scenario B demonstrates the centering fix — 2 heroes land at cols 1–2, not 0–1.
  • Scenario D shows enemy overflow: 4 in front row, 1 in back row (centered in its row, col 5).
  • Top 20% of battlefield = sky band (darkened gradient). Grid starts at 20% down.
  • All numbers are computed live from the formula in Phase 04 spec — no hardcoded positions.
